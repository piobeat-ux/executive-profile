# Executive Profile — Валерий Григорчук

Профессиональный адаптивный лендинг для руководителя уровня CEO / Генеральный директор / Управляющий директор.

## Структура
- `index.html` — главная страница, адаптивные стили встроены
- `portrait.webp` — локальная фотография
- `cv.html` — резервная онлайн-версия полного резюме

Кнопка «Полное резюме PDF» ведёт на [Яндекс Диск](https://disk.yandex.ru/i/kjXQV89_2f15mg).

## Развёртывание в Timeweb Cloud App Platform

1. Подключите GitHub `piobeat-ux`.
2. Выберите репозиторий `piobeat-ux/executive-profile` и ветку `main`.
3. Тип приложения: **HTML/CSS/JS** (статический сайт); корень проекта: **/**.
4. Команды сборки и запуска не требуются.
5. Включите автоматическое развёртывание при изменениях ветки `main`.
6. Разверните сайт сначала на техническом домене Timeweb Cloud и проверьте `/`, `/portrait.webp`, `/cv.html`, ссылки на почту, телефон и PDF.
7. После проверки подключите `cv.vgrigorchuk.ru`, обновив **только DNS-запись поддомена cv** у REG.RU согласно настройкам Timeweb. Не изменяйте MX, SPF, DKIM или NS всего домена. Vercel сохраняется как резерв.

## Контроль

- Проверить iOS/Android и браузеры Safari, Chrome, Яндекс Браузер без VPN.
- Проверить ширины 320, 375, 390, 430, 768 и 1280 px.
- Проверить HTTPS, сертификат и внешнюю доступность.
- Публичный сайт не должен содержать внутренних коммерческих показателей действующего корпоративного заказчика.
